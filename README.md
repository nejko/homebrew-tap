# nejko/homebrew-tap

Homebrew formulae by Nejc Skoberne.

| Formula | What it is |
|---|---|
| [claude-focus](https://github.com/nejko/claude-focus) | One priority queue over all your Claude Code sessions in herdr or iTerm2 |

```sh
brew install nejko/tap/claude-focus
claude-focus setup
```

Upgrade with `brew upgrade claude-focus && claude-focus setup`; setup
restarts the background service on the new code.
